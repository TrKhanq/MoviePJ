# Rikkei Cinema - Responsive Movie Theater Website

A modern, responsive movie theater website built with HTML, CSS, and JavaScript. Features include movie listings, booking system, user authentication, and special promotions.

## Features

- **Responsive Design**: Works seamlessly on all devices (mobile, tablet, desktop)
- **Movie Listings**: Browse currently showing movies with pagination
- **User Authentication**: Login and registration system
- **Booking System**: Online ticket reservation
- **Admin Panel**: Manage movies and bookings
- **Special Promotions**: Display current deals and offers
- **Modern UI**: Clean, cinema-themed interface with smooth animations

## Technology Stack

- **Frontend**: HTML5, CSS3, JavaScript (ES6+)
- **Styling**: CSS Grid, Flexbox, CSS Variables
- **Icons**: Bootstrap Icons
- **Fonts**: Google Fonts (Inter, Cabin, Montserrat)
- **Storage**: LocalStorage for data persistence

## File Structure

```
docs/
    index.html          # Main homepage
    login.html          # User login page
    register.html       # User registration page
    booking.html        # Movie booking page
    admin.html          # Admin dashboard
    css/
        index.css       # Main styles
        responsive.css  # Responsive design
        login.css       # Login page styles
        register.css    # Registration page styles
        booking.css     # Booking page styles
        admin.css       # Admin panel styles
    js/
        index.js        # Main page functionality
        login.js        # Login functionality
        register.js     # Registration functionality
        booking.js      # Booking functionality
        admin.js        # Admin functionality
        models/
            movies.js   # Movie data model
            users.js    # User data model
            tickets.js  # Ticket data model
    assets/             # Static assets
```

## Responsive Breakpoints

- **Mobile**: 320px - 575px
- **Small Tablet**: 576px - 767px
- **Tablet**: 768px - 991px
- **Small Desktop**: 992px - 1199px
- **Large Desktop**: 1200px+

## Getting Started

1. Clone this repository
2. Navigate to the `docs` folder
3. Open `index.html` in your browser
4. Or deploy to GitHub Pages for live hosting

## GitHub Pages Deployment

This project is optimized for GitHub Pages deployment:

1. Enable GitHub Pages in your repository settings
2. Select the `docs` folder as the source
3. The site will be automatically deployed
